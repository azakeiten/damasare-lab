# だまされ体験ラボ

**だまされる前に、気づく練習を。**

スマホの中で進む会話に返信しながら、詐欺や消費者トラブルを体験する分岐ストーリーゲームです。覚えるのは手口ではなく、「おかしいと気づくサイン」。

▶ **遊ぶ：https://azakeiten.github.io/damasare-lab/**

- **毎回ちがう話**：14の場面と手口を組み合わせて、開くたびに新しいストーリーを作る（`#mix`）。日付で決まる「今日の1話」も。話ごとにリンクがあり、同じ話を共有できる
- **相手はあきらめない**：早く見抜いて「被害なし」になっても、相手が数日後に別の手口でもう一度近づいてくる。しつこい相手も撃退するとボーナス
- **書いた言葉に、相手が反応する**：自分の言葉で返信すると、相手がその内容（「親に相談」「警察」「確認」など）に合わせて返してくる
- **大きな選択肢は3つ**：もとの選択肢に「ためらう」が加わる。ためらうと、相手はメッセージを取り消して、条件をゆるめたり気持ちにうったえたりしてくる
- **はじまりはスマホの画面から**：メッセージやウェブの話はロック画面に届く通知から、電話の話は着信画面（拒否・応答）から、訪問の話はインターホン画面から始まる。「この話の場面」もそこで読める
- **相手が返事をせかしてくる**：選択肢の前で考えこんでいると、相手から「まだですか？」と催促が届く（画面が小さくふるえ、ウェブの場面では通知が落ちてくる）。結果画面で、せかされた回数をふりかえる。「やさしい表示」では出ない
- **本音モード**：話を終えたあと「本音モードでもう一度」を選ぶと、だます側の「心の声」が灰色の吹き出しで見える（「考えさせたら負け。今すぐ決めさせよう」など）。気づけたときは「ちっ、ここで止まるか」、見逃したときは「よし、かかった」と相手の反応も見える
- **1か月後のエピローグ**：話を終えたあと「友だちから相談が来た」を選ぶと、同じ手口のメッセージを友だちに見せられ、こんどは教える側として返事をえらぶ。正しく教えられると「友だちを守れた」（+15 XP）、まちがえると友だちが被害にあう様子が描かれ、えらび直せる
- **失敗はちゃんと失敗に**：被害の結末では、銀行やカード会社の通知が届いて画面がゆれる。被害はなくても、サインを2つ以上見逃したら「被害なし（ギリギリ）」
- **返し方はいろいろ**：選択肢をえらぶほか、「聞き返す」「相談する」「相手を確かめる（プロフィール・電話番号・名刺）」「調べる」「時間をおく」「記録を残す」もできる。入力欄に自分の言葉で書くと、ことばから「断る・確かめる」か「相手の話に乗る」かを読み取って物語が進む（入力はどこにも送られない）。キーボードの A〜F でもえらべる
- **場面ごとの画面**：電話は通話中の画面、ウェブはアドレスバーつき。知らない番号からの連絡には印がつく
- **守りゲージ**：お金・個人情報・人間関係・冷静さの4つ。見逃したサインの種類に合わせて減っていき、結果画面にも残る
- **分岐のたびに「STOP」**：選んだ直後に話が止まり、そこで気づけたサインを解説。サインがかくれていたメッセージに印がつき、迷ったら「ミヌケのヒント」も使える
- **ストーリーマップ**：分かれ道の全体図に、通った場面・今回のルート・回収した結末を表示
- **結果画面**：「手口の解剖」（相手が使った手口と、見抜けた数）。判定のあと「ふりかえり／裏側（だます側の台本）／まとめ／伝える」のタブで見られる。通ったルート（分かれ道からやり直せる）、シナリオのまとめ（よくある流れ・断りのひとこと・被害にあったらすぐやること・制度・話し合いの問い）、シェア用の画像（紺と金のデザインで、判定・気づけたサイン・守りゲージ入り）
- **見抜きチャレンジ**：届いたメッセージを「あやしい／だいじょうぶ」で判定。日替わりの10問、ライフ3つのエンドレス、2通を見くらべる「どっちが安全？」、自分の言葉で返信を書いて★3つで判定される「ことばで返す」、毎回ちがう話を3本続けて級（初級〜名人）と認定証がもらえる「見抜き検定」。問題は毎回変わる
- **あそびかたマップ**（ホーム）：体験する・見抜く・ふりかえる・くらしで使う の4つに分けて、14の遊び方と道具をタイルで一覧。押すと、そのモードや場所にすぐ移動する
- **画面のワナさがし**：通販の購入画面・サブスクの解約画面・ガチャ・アプリの設定画面・偽の通販サイト・投資アプリ・フリマ・偽のウイルス警告（全8画面）など、本物そっくりの画面から「だます仕掛け」（カウントダウン、最初からチェックの定期便、見つけにくい解約リンク など）を見つける4問
- **サインさがし**：メッセージの中の「あやしいところ」を自分でタップして見つける6問（全12問から出題）。答え合わせでは、見つけたサイン・見落とし・うたがいすぎが色分けされ、1つずつ解説が出る
- **ミヌケの着せかえ**（サイン図鑑のページ）：見抜きレベル3・6・10・15・20で、まるメガネ・探偵の帽子・ヘッドホン・マフラー・王冠が手に入り、ホームや結果画面のミヌケに着せられる
- **称号**：「先生デビュー」「みんなの守り手」（エピローグで友だちを守る）、「本音を見た」、「サインさがし名人」、「メッセージ点検係」、「わが家の約束」などを追加。図鑑の「守りのかたち」に、友だちを守った話の数を表示
- **見抜きレベル**：シナリオ・クイズ・チャレンジで経験値がたまり、レベルと称号が上がり続ける
- **学びのコース**：「はじめての5本」「スマホ・SNS編」「ひとり暮らし準備編」「推し活編」「進学・就職編」「お金の話編」「家族を守る編」の7コース。進み具合つき
- **ふりかえり帳**：体験した話と結末を、日付ごとに記録（サイン図鑑のページ）。結果画面で書いた「気づきメモ」（次はこうする、のひとこと）も一緒に残る
- **家族や友だちに話す**：結果画面に、体験したことを身近な人に伝えるひとこと
- **くっきり表示**：右上の「表示」ボタンで、自動・ライト・ダークに加えて「くっきり」（黒地に白文字、強調は黄色、境目を太く）を選べる。見えにくい人や、明るい場所で使うときに
- **やさしい表示（家族と使う）**：文字と選択肢を大きくし、小さな行動と自由入力をかくして、えらぶだけで進める。相談先ページの「家族といっしょに使う」と体験画面で切りかえ
- **読み上げ**：オンにすると、相手のメッセージやできごとをブラウザの音声で読み上げる。相手ごとに声の高さが変わり、「やさしい表示」のときはゆっくり読む（体験画面の横や、相談先のページの「家族といっしょに使う」から切りかえ）
- **季節の注意報**：月ごとに「いま気をつけたい手口」をホームに表示（4月は新生活、9月は台風、1月は成人式など）
- **今日のメニュー**：一度遊んだ人には、ホームのいちばん上に「今日の1話・今日のチャレンジ・つづき・苦手克服・検定」をまとめて表示
- **ピンチ演出**：体験中、サインを見逃して「あぶなさ」が上がると、スマホの画面のふちが赤く脈打つ（危ないほど速く・濃く）。サインに気づいた瞬間はふちが金色に、見逃した瞬間は赤く光る
- **エンドカード**：結末に着いた瞬間、スマホの画面に「CASE CLOSED（被害なし）」「DAMAGE CONTROL（被害を最小限に）」「DAMAGE（被害が発生）」のハンコがドンと押され、気づけたサインの数が出てから結果画面へ
- **オープニング**：話を開くと、スマホの画面に「CASE FILE No.」つきのタイトルカードが出る。ジャンル・タグ・タイトル（1文字ずつ浮かぶ）・あなたの立場・時刻・サインの数を見せてから始まる。押すとすぐ閉じ、2回目からは短く（やさしい表示・動きをへらす設定では出ない／すぐ消える）
- **立ち止まりフローチャート**（相談先のページ）：いま来ている話について「お金の話が出た？」「急かされている？」など6つの質問に答えると、STOP・CHECK・OKの判定と、次にすること、同じサインが出てくる練習用の話が出る
- **守りの待ち受け**（相談先のページ）：「急かされたら、いったん止まる。」など6つのひとことと4つの色から、スマホのロック画面用の壁紙（1080×1920）をつくって保存できる。時計と重ならないよう、ひとことと「188・#9110」は下半分に
- **同じサインが出てくる、別の話**（結果画面）：いま終えた話と同じ系統のサインが2つ以上出てくる話を、ちがうジャンルからも3本おすすめ。共通するサインの系統と「まだ／体験ずみ」がひと目でわかる
- **つづけた日カレンダー**（サイン図鑑のページ）：体験した日を16週間のマス目に色でならべる（多い日ほど金色）。連続日数・最長の連続・体験した日の数と、ミヌケのひとことつき
- **だましが届く時間**（相談先のページ）：全シナリオの「はじまりの時刻」を24時間の時計グラフにならべる。時間をえらぶと、その時間帯に気をつけたいことと、その時間に始まる話が出る（矢印キーでも動かせる）
- **コースの修了証**（サイン図鑑のページ）：学びのコースの話を全部体験すると、名前入りの修了証（紺と金のふち・朱色の「見抜 修了」の印）をつくれる。画像で保存・印刷ができ、コースを修了した結果画面からもつくれる
- **188に相談する練習**：結果画面の「188 相談する練習」や、あそびかたマップから。相談員の5つの質問（何の話か・いつどこで・何を言われたか・お金・記録）に答えると、伝わる話し方のヒントが出て、最後に「相談メモ」ができる（コピーできる）
- **あとで体験リスト**：シナリオのカードの★を押すと、ホームの「あとで体験する」の棚に集まる。一覧の「★あとで体験」でしぼりこみもできる（この端末の中だけに保存）
- **探しやすい一覧**：ジャンル・場面（メッセージ・電話・対面・ウェブ）・立場（中学生・高校生・大学/専門学校・社会人・家族を守る）でしぼりこみ、「未体験だけ」「ランダムに1本」
- **YES/NO診断**：自分に近いシナリオを3本おすすめ
- **サインあてクイズ**：物語のメッセージから、サインの系統を当てる5問
- **あなたの守りのかたち**（サイン図鑑のページ）：8つの系統の見抜き率をレーダーチャートで表示。体験の中でよく使う行動（確かめる・聞き返す・相談する など）から「相談上手タイプ」「確かめ探偵タイプ」などの守りのタイプと、いちばん強い系統・のびしろの系統がわかる
- **体験マップ**：全シナリオをジャンルごとのマス目で一覧（まだ・クリア・結末コンプリート）。マスを押すとその話へ
- **相手の人物帳**：これまでに出会った「相手」を顔の一覧で集める（サイン図鑑のページ）。押すと、最初のひとこと・使ってきた手・見抜くポイントが見られる。まだ会っていない相手は「？」のまま
- **サイン図鑑**：系統と状態（気づけた・見逃した・未発見）でしぼりこめる。サインを9つの系統に分けて収集。系統ごとの見抜き率グラフと、14の称号つき
- **話し合いカード**（授業で使うページ）：コースをえらぶと、話ごとに「見抜くポイント」と「話し合いの問い」が入ったカードをA4に2列でまとめて印刷できる
- **授業で使う**：結果画面の「まとめ」から、その話の印刷用ワークシート（A4・1枚）を印刷できる。スクリーンに映してクラスで考える「スクリーンモード」、教室で配るQRコード、50分の授業案、シナリオ一覧表、話し合いの問い、ふりかえりシート、使うときの配慮
- **届いたメッセージをチェック**（相談先のページ・ホームの NEW から）：あやしいメッセージを貼りつけると、サインになりやすい言葉に系統ごとの色をつけ、あやしさの目安（4段階）と、似たサインが出てくる話を3本表示する。判定は端末の中だけで行い、どこにも送らない
- **相談先**：だましの決まり文句ランキング（全シナリオのセリフから「今日だけ」「必ず」などを自動で数える）、188（消費者ホットライン）、#9110（警察相談専用電話）、わたしの断りことば帳（自分で書いた断りの返信が集まる）、知っておきたいことば20語、断りのひとこと集
- **わが家の守りの約束カード**（相談先のページ）：家族で約束を6つまでえらび、家の呼び名と「迷ったら連絡する人」を入れると、紺と金のカード画像ができる。保存・印刷して、電話のそばにはっておける（合言葉はカードに書かない）

進み具合や図鑑の記録は、そのブラウザの中（localStorage）だけに保存されます。サーバーに送られる情報はありません。

## 内容について

ストーリーと登場人物はすべてフィクションです。国民生活センター・消費者庁・金融庁・警察庁などが公開している注意喚起の傾向をもとに、手口の再現ではなく「気づくサイン」に焦点をしぼって構成しています。金額・条件・手数料は説明のための例です。クーリング・オフの期間などの制度は一般的な内容をまとめたものです。正確な条件や最新の情報は、各機関のサイトや188でご確認ください。

### シナリオの追加のしかた

`data/` のファイルに、次の形のオブジェクトを `window.DL.scenarios.push(...)` で足します。

```js
{
  id: "example", genre: "kasegu", tag: "タグ", title: "タイトル", sub: "ひとこと説明",
  mins: 5, level: 2, clock: "21:00", intro: "あらすじ",
  cast: { a: { n: "名前", i: "頭文字", h: 200, r: "役どころ" } },
  signs: { s1: { cat: "umai", t: "サインの名前", d: "解説" } },
  start: "n1",
  nodes: {
    n1: { scene: { type: "dm", app: "SNS", who: "a" }, time: "21:00", log: [["them", "メッセージ"], ["think", "心の声"]],
          choices: [{ say: "返信", next: "e1", sign: "s1", ok: false }, { act: "行動", next: "e2", sign: "s1", ok: true }] },
    e1: { end: "bad", h: "結末の見出し", p: "結末の説明" },
    e2: { end: "safe", h: "結末の見出し", p: "結末の説明" }
  }
}
```

サインに `ask: ["こちらの質問", "相手の返し1", "相手の返し2"]` を足すと、「聞き返す」を選んだときの会話をその場面に合わせられます（ないときは系統ごとの共通の会話）。

`cat`（サインの系統）は `umai` `isogi` `himitsu` `kane` `kojin` `kankei` `jouken` `tsuuchi` `soudan` のどれか。`data/debrief.js` にまとめを足すと、結果画面と授業ページに表示されます。
