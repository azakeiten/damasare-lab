# だまされ体験ラボ

**だまされる前に、気づく練習を。**

スマホの中で進む会話に返信しながら、詐欺や消費者トラブルを体験する分岐ストーリーゲームです。覚えるのは手口ではなく、「おかしいと気づくサイン」。

▶ **遊ぶ：https://azakeiten.github.io/damasare-lab/**

企画・制作：[AZAKEI（麻経）](https://azakeiten.github.io/)　麻布中学校・高等学校 経済系同好会

- **毎回ちがう話**：14の場面と手口を組み合わせて、開くたびに新しいストーリーを作る（`#mix`）。日付で決まる「今日の1話」も。話ごとにリンクがあり、同じ話を共有できる
- **相手はあきらめない**：早く見抜いて「被害なし」になっても、相手が数日後に別の手口でもう一度近づいてくる。しつこい相手も撃退するとボーナス
- **書いた言葉に、相手が反応する**：自分の言葉で返信すると、相手がその内容（「親に相談」「警察」「確認」など）に合わせて返してくる
- **大きな選択肢は3つ**：もとの選択肢に「ためらう」が加わる。ためらうと、相手はメッセージを取り消して、条件をゆるめたり気持ちにうったえたりしてくる
- **失敗はちゃんと失敗に**：被害の結末では、銀行やカード会社の通知が届いて画面がゆれる。被害はなくても、サインを2つ以上見逃したら「被害なし（ギリギリ）」
- **返し方はいろいろ**：選択肢をえらぶほか、「聞き返す」「相談する」「相手を確かめる（プロフィール・電話番号・名刺）」「調べる」「時間をおく」「記録を残す」もできる。入力欄に自分の言葉で書くと、ことばから「断る・確かめる」か「相手の話に乗る」かを読み取って物語が進む（入力はどこにも送られない）。キーボードの A〜F でもえらべる
- **場面ごとの画面**：電話は通話中の画面、ウェブはアドレスバーつき。知らない番号からの連絡には印がつく
- **守りゲージ**：お金・個人情報・人間関係・冷静さの4つ。見逃したサインの種類に合わせて減っていき、結果画面にも残る
- **分岐のたびに「STOP」**：選んだ直後に話が止まり、そこで気づけたサインを解説。サインがかくれていたメッセージに印がつき、迷ったら「ミヌケのヒント」も使える
- **ストーリーマップ**：分かれ道の全体図に、通った場面・今回のルート・回収した結末を表示
- **結果画面**：「手口の解剖」（相手が使った手口と、見抜けた数）。判定のあと「ふりかえり／裏側（だます側の台本）／まとめ／伝える」のタブで見られる。通ったルート（分かれ道からやり直せる）、シナリオのまとめ（よくある流れ・断りのひとこと・被害にあったらすぐやること・制度・話し合いの問い）、シェア用の画像（紺と金のデザインで、判定・気づけたサイン・守りゲージ入り）
- **見抜きチャレンジ**：届いたメッセージを「あやしい／だいじょうぶ」で判定。日替わりの10問、ライフ3つのエンドレス、2通を見くらべる「どっちが安全？」、自分の言葉で返信を書いて★3つで判定される「ことばで返す」、毎回ちがう話を3本続けて級（初級〜名人）と認定証がもらえる「見抜き検定」。問題は毎回変わる
- **見抜きレベル**：シナリオ・クイズ・チャレンジで経験値がたまり、レベルと称号が上がり続ける
- **学びのコース**：「はじめての5本」「スマホ・SNS編」「ひとり暮らし準備編」「推し活編」「進学・就職編」「お金の話編」「家族を守る編」の7コース。進み具合つき
- **ふりかえり帳**：体験した話と結末を、日付ごとに記録（サイン図鑑のページ）
- **家族や友だちに話す**：結果画面に、体験したことを身近な人に伝えるひとこと
- **やさしい表示（家族と使う）**：文字と選択肢を大きくし、小さな行動と自由入力をかくして、えらぶだけで進める。相談先ページの「家族といっしょに使う」と体験画面で切りかえ
- **季節の注意報**：月ごとに「いま気をつけたい手口」をホームに表示（4月は新生活、9月は台風、1月は成人式など）
- **今日のメニュー**：一度遊んだ人には、ホームのいちばん上に「今日の1話・今日のチャレンジ・つづき・苦手克服・検定」をまとめて表示
- **探しやすい一覧**：ジャンル・場面（メッセージ・電話・対面・ウェブ）でしぼりこみ、「未体験だけ」「ランダムに1本」
- **YES/NO診断**：自分に近いシナリオを3本おすすめ
- **サインあてクイズ**：物語のメッセージから、サインの系統を当てる5問
- **体験マップ**：全シナリオをジャンルごとのマス目で一覧（まだ・クリア・結末コンプリート）。マスを押すとその話へ
- **サイン図鑑**：系統と状態（気づけた・見逃した・未発見）でしぼりこめる。サインを9つの系統に分けて収集。系統ごとの見抜き率グラフと、14の称号つき
- **授業で使う**：結果画面の「まとめ」から、その話の印刷用ワークシート（A4・1枚）を印刷できる。スクリーンに映してクラスで考える「スクリーンモード」、教室で配るQRコード、50分の授業案、シナリオ一覧表、話し合いの問い、ふりかえりシート、使うときの配慮
- **相談先**：だましの決まり文句ランキング（全シナリオのセリフから「今日だけ」「必ず」などを自動で数える）、188（消費者ホットライン）、#9110（警察相談専用電話）、わたしの断りことば帳（自分で書いた断りの返信が集まる）、知っておきたいことば20語、断りのひとこと集

進み具合や図鑑の記録は、そのブラウザの中（localStorage）だけに保存されます。サーバーに送られる情報はありません。

## 内容について

ストーリーと登場人物はすべてフィクションです。国民生活センター・消費者庁・金融庁・警察庁などが公開している注意喚起の傾向をもとに、手口の再現ではなく「気づくサイン」に焦点をしぼって構成しています。金額・条件・手数料は説明のための例です。クーリング・オフの期間などの制度は一般的な内容をまとめたものです。正確な条件や最新の情報は、各機関のサイトや188でご確認ください。

### シナリオの追加のしかた

`data/` のファイルに、次の形のオブジェクトを `window.DL.scenarios.push(...)` で足します。

```js
{
  id: "example", genre: "kasegu", tag: "タグ", title: "タイトル", sub: "ひとこと説明",
  mins: 5, level: 2, clock: "21:00", intro: "あらすじ",
  cast: { a: { n: "名前", i: "頭文字", h: 200, r: "役どころ" } },
  signs: { s1: { cat: "umai", t: "サインの名前", d: "解説" } },
  start: "n1",
  nodes: {
    n1: { scene: { type: "dm", app: "SNS", who: "a" }, time: "21:00", log: [["them", "メッセージ"], ["think", "心の声"]],
          choices: [{ say: "返信", next: "e1", sign: "s1", ok: false }, { act: "行動", next: "e2", sign: "s1", ok: true }] },
    e1: { end: "bad", h: "結末の見出し", p: "結末の説明" },
    e2: { end: "safe", h: "結末の見出し", p: "結末の説明" }
  }
}
```

サインに `ask: ["こちらの質問", "相手の返し1", "相手の返し2"]` を足すと、「聞き返す」を選んだときの会話をその場面に合わせられます（ないときは系統ごとの共通の会話）。

`cat`（サインの系統）は `umai` `isogi` `himitsu` `kane` `kojin` `kankei` `jouken` `tsuuchi` `soudan` のどれか。`data/debrief.js` にまとめを足すと、結果画面と授業ページに表示されます。
